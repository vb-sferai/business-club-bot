# Бот Бизнес-Клуба

Telegram-бот для приёма заявок в закрытый бизнес-клуб с админ-панелью: просмотр заявок, одобрение/отклонение, рассылки, личные сообщения, редактирование текстов прямо из бота.

## Что внутри

- Анкета из 4 шагов: имя → телефон → ник в Telegram → комментарий.
- **❓ Вопросы от пользователей** — после подачи заявки появляется кнопка «Задать вопрос». Команда `/ask` работает у всех в любой момент.
  - Все вопросы хранятся в БД (таблица `questions`).
  - Админ получает уведомление в личку при каждом новом вопросе с кнопкой «Ответить».
  - Ответ из админки уходит пользователю как обычное сообщение бота — можно отправить текст, фото, видео или документ.
- Хранение заявок и вопросов в SQLite (`club.db`).
- Все тексты сообщений редактируются:
  - **из бота** через `/admin` → «📝 Редактировать сообщения»;
  - **руками** — в файле `messages.json` (бот подхватит изменения).
- Админ-панель `/admin`:
  - 📋 Заявки на рассмотрении / одобренные / отклонённые
  - ✅/❌ Одобрить или отклонить заявку (с авто-уведомлением заявителю)
  - ❓ Вопросы пользователей (новые / отвеченные / закрытые), счётчик новых прямо на кнопке
  - 💬 Ответить на вопрос — текстом, фото, видео или документом
  - 💌 Написать конкретному пользователю
  - 📢 Рассылка всем пользователям бота
  - 📊 Статистика по заявкам и вопросам
- При одобрении/отклонении и при ответе на вопрос автоматически отправляется уведомление пользователю.

## Запуск

### 1. Получить токен

Откройте [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → следуйте инструкциям. На выходе получите токен вида `123456789:AAA-...`.

### 2. Узнать свой Telegram ID

Можно через [@userinfobot](https://t.me/userinfobot) или после запуска бота отправить ему `/id`.

### 3. Установить зависимости

Требуется **Python 3.10+**.

```bash
cd business_club_bot
python -m venv .venv
source .venv/bin/activate          # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 4. Настроить `.env`

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```
BOT_TOKEN=123456789:AAA-bbb-CCC...
ADMIN_IDS=ВАШ_ТЕЛЕГРАМ_ID
```

Если админов несколько — через запятую: `ADMIN_IDS=111,222,333`.

### 5. Запустить

```bash
python bot.py
```

В логах увидите `Бот запущен: @your_bot`. Откройте бота в Telegram и отправьте `/start` — должно появиться приветственное сообщение и кнопка «📝 Подать заявку».

## Как редактировать тексты

### Способ 1 — через бота (рекомендуется)

1. В Telegram у вашего бота отправьте `/admin`.
2. Нажмите «📝 Редактировать сообщения».
3. Выберите сообщение из списка.
4. Бот покажет текущий текст — отправьте новый одним сообщением.
5. Поддерживается HTML: `<b>жирный</b>`, `<i>курсив</i>`, `<a href="https://...">ссылка</a>`. Если разметка некорректна — бот предупредит и не сохранит.

### Способ 2 — в файле `messages.json`

Откройте `messages.json` в любом редакторе и поменяйте значения. Перезапуск бота не нужен — он читает файл при каждом обращении.

Ключи и их назначение:

| Ключ                      | Когда показывается                                     |
| ------------------------- | ------------------------------------------------------ |
| `welcome`                 | Приветствие при `/start`                               |
| `ask_name`                | Запрос имени                                           |
| `ask_phone`               | Запрос телефона                                        |
| `ask_username`            | Запрос ника в Telegram                                 |
| `ask_comment`             | Запрос комментария                                     |
| `application_received`    | Подтверждение приёма заявки                            |
| `already_applied`         | Если человек уже подавал заявку                        |
| `approved_notification`   | Уведомление пользователю при одобрении заявки админом  |
| `rejected_notification`   | Уведомление пользователю при отклонении заявки админом |
| `ask_question_invite`     | Приглашение задать вопрос (под кнопкой после заявки)   |
| `ask_question_prompt`     | Просьба написать вопрос                                |
| `question_received`       | Подтверждение получения вопроса                        |
| `answer_intro`            | Шапка ответа админа (перед цитатой вопроса)            |

## Админ-команды

| Команда   | Кому доступна | Что делает                            |
| --------- | ------------- | ------------------------------------- |
| `/start`  | Всем          | Приветствие и начало регистрации      |
| `/ask`    | Всем          | Задать вопрос в любой момент          |
| `/admin`  | Только админу | Открывает админ-панель                |
| `/cancel` | Всем          | Прерывает текущий шаг (анкета/ответ)  |
| `/id`     | Всем          | Показывает свой Telegram user_id      |

## Рассылка и личные сообщения

Бот пересылает то сообщение, которое вы отправили во время рассылки/ЛС, через `copy_message` — поэтому можно отправлять не только текст, но и фото с подписью, видео, голосовые, документы. Получатель видит сообщение как обычное сообщение от бота (без указания, что оно было переслано).

## Развёртывание на сервере

Простой вариант — `systemd`-сервис на любом VPS:

```ini
# /etc/systemd/system/club-bot.service
[Unit]
Description=Business Club Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/business_club_bot
ExecStart=/opt/business_club_bot/.venv/bin/python bot.py
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now club-bot
sudo journalctl -u club-bot -f       # смотреть логи
```

## Бэкап заявок

База — обычный SQLite-файл `club.db`. Достаточно скопировать его:

```bash
cp club.db club.db.backup.$(date +%F)
```

Если хочется выгрузить заявки в Excel — можно открыть `club.db` через DBeaver / DB Browser for SQLite и сделать экспорт таблицы `users` в CSV/XLSX.
